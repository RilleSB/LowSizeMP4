## 🌟 Почему LowSizeMp4?

Обычные утилиты для сжатия либо перегружены непонятными терминами консоли, либо портят качество видео до неузнаваемости. **LowSizeMp4** объединяет мощь профессионального движка **FFmpeg** с элегантным интерфейсом в стиле **Windows 11 Fluent Design**:
- 🎯 **Точно в размер**: нужно ровно 10 МБ для бесплатного Discord или 50 МБ для Telegram? Программа сама подберёт идеальный битрейт видео и звука с точностью до килобайта.
- ⚡ **Тест за 5 секунд**: не тратьте время на долгое сжатие всего фильма, чтобы проверить настройки — нажмите «Тест» и оцените 5-секундный кусочек из середины ролика.
- 🚀 **Аппаратное ускорение**: автоматическое задействование видеокарт NVIDIA (NVENC), Intel (QuickSync) и AMD (AMF).
- 🎨 **Полная кастомизация**: Mica, Acrylic, тёмная и светлая темы, выбор любого акцентного цвета из палитры или по HEX-коду.

## ✨ Ключевые возможности

### 🎯 1. Два умных режима сжатия
* **По профилю качества**:
  * ⚖️ **Сбалансированное (H.264)** — оптимальный компромисс между весом и качеством (CRF 23, AAC 128k).
  * 🗜️ **Максимальное сжатие (H.265 / HEVC)** — максимальное уменьшение размера с сохранением чёткости.
  * 💬 **Для Discord / Мессенджеров** — оптимизировано под быструю загрузку в мобильных сетях.
  * ⚡ **Быстрое сжатие** — кодирование за считанные секунды с пресетом `faster`.
  * 💎 **Без потери качества** — визуально неотличимо от исходника (CRF 19, AAC 192k).
* **Точный размер (Fit to MB)**:
  * Быстрые пресеты в один клик: **10 МБ** (Discord Free), **25 МБ** (Discord Nitro / Почта), **50 МБ** (Telegram), **100 МБ** или произвольный ввод любого размера в мегабайтах.
  * Битрейт рассчитывается математически точно с учётом длительности файла или обрезанного отрезка.

### ⚡ 2. Быстрый тестовый сэмпл (5 секунд)
* Кнопка **«⚡ Тест (5 сек)»** мгновенно вырезает 5-секундный фрагмент из середины видео и пережимает его с текущими параметрами (FPS, кодек, размер, фильтры).
* Готовый сэмпл автоматически открывается в видеоплеере для оценки картинки перед основным запуском.

### ✂️ 3. Обрезка видео (Trimming)
* Возможность вырезать нужный фрагмент прямо в карточке файла (начало и конец в формате `ЧЧ:ММ:СС` или `ММ:СС`).
* При сжатии в точный размер лимит МБ применяется именно к вырезанному таймлайну.

### 🎞️ 4. Форматы вывода и современные кодеки
* **Форматы файлов**:
  * **MP4 Видео** — универсальный видеофайл.
  * **GIF Анимация** — генерация плавной гифки через двухпроходную палитру FFmpeg (`palettegen` + `paletteuse`), без пикселизации и цветового шума.
  * **MP3 Аудио** — быстрое извлечение чистой аудиодорожки (192 kbps).
* **Видеокодеки (для MP4)**:
  * **H.264 (AVC)** — стопроцентная совместимость со всеми плеерами, старыми смартфонами и браузерами.
  * **H.265 (HEVC)** — сверхвысокая эффективность с тегом `-tag:v hvc1` (нативная поддержка в Windows Media Player, QuickTime, iOS и macOS).
  * **AV1** — ультрасовременный открытый кодек с поддержкой GPU (NVENC/QSV/AMF) и программного кодировщика `libsvtav1`.

### 🚀 5. Аппаратное ускорение (GPU)
* Автоматическое определение поддерживаемых аппаратных енкодеров:
  * **NVIDIA NVENC** (`h264_nvenc`, `hevc_nvenc`, `av1_nvenc`)
  * **Intel QuickSync** (`h264_qsv`, `hevc_qsv`, `av1_qsv`)
  * **AMD AMF** (`h264_amf`, `hevc_amf`, `av1_amf`)
* Перекодирование в 3–5 раз быстрее без нагрузки на процессор.

### 📐 6. Разрешение, FPS и плавная интерполяция
* **Масштабирование кадра**: Оригинал, 1080p, 720p, 480p с умным сохранением пропорций (`scale=-2:min(...,ih)`).
* **Частота кадров**: Оригинал, 120 FPS, 60 FPS, 50 FPS, 30 FPS, 24 FPS, 15 FPS или **Свой FPS** (144, 90, 75 и др.).
* **Интерполяция (`minterpolate`)**: генерация новых промежуточных кадров на основе векторов движения для ультра-плавной картинки.

### ⏱️ 7. Панель задач Windows и динамический ETA
* Индикатор выполнения (`TaskbarItemInfo`) отображает зелёный прогресс прямо на иконке приложения в панели задач Windows 11/10.
* Точный расчёт оставшегося времени (ETA: *«Осталось: ~01:30»*), текущего FPS и скорости кодирования (например, `2.4x`).

### 🌙 8. Автоматизация после завершения
* Выбор действия по окончании всей очереди:
  * **Ничего не делать**
  * **Спящий режим (Sleep)**
  * **Выключить ПК (Shutdown)** с возможностью отмены таймера.
* Звуковые оповещения и авто-открытие папки с готовыми роликами.

### 🎨 9. Fluent Design и кастомизация тем
* Эффекты подложки: **Mica** (Слюда Windows 11), **Acrylic** (Акриловое размытие) или сплошной фон.
* Темы: **🌙 Тёмная**, **☀️ Светлая**, **💻 Высокий контраст**.
* Выбор акцентного цвета из палитры (Windows Blue, Cyberpunk, Electric Neon, Emerald, Sunset Orange и др.) или ввод произвольного **HEX-кода** (например, `#FF007F`).

### 🖱️ 10. Удобство работы и Windows Shell
* Drag & Drop файлов любого видеоформата (`.mp4`, `.mkv`, `.mov`, `.avi`, `.webm`, `.flv`, `.wmv`, `.ts`).
* Запуск через **«Открыть с помощью»** или передача путей в командной строке (CLI).
* Встроенный загрузчик актуального FFmpeg из GitHub в один клик прямо из вкладки «Настройки».

## 🚀 Сборка и запуск

### Требования
* Windows 10 (версия 1809+) или Windows 11 (x64)
* [.NET 9.0 SDK](https://dotnet.microsoft.com/download/dotnet/9.0) (для сборки из исходников)

### Запуск в режиме разработки
```bash
# Клонирование репозитория
git clone https://github.com/RilleSB/LowSizeMP4.git
cd LowSizeMP4/LowSizeMp4

# Сборка и запуск
dotnet run
```

### Сборка автономного Single-File EXE (без внешних зависимостей)
Для получения единого `.exe` файла, которому не требуется установленный .NET на целевом компьютере:
```bash
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o ../publish
```
После завершения в папке `publish/` появится файл `LowSizeMp4.exe` со всеми встроенными библиотеками и ресурсами.
